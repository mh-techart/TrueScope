# TrueScope

**Viewport Scopes for Unreal Engine.**

TrueScope adds Waveform, RGB Parade, Vectorscope and Histogram scopes to the
Unreal Editor in a dockable window — judge exposure and color inside the
engine instead of after rendering. It measures the active viewport after
tonemapping (WYSIWYG), keeps a zero footprint in your levels, and targets
Windows, macOS and Linux.

> **Work in progress** — not ready for production use.
